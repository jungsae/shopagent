# 배송정책
확정: 2026-11-02 (KST)

- DL-01 3만 원 이상 무료배송, 미만 3,000원.
- DL-02 평일 오후 2시 전 결제는 당일 출고.
- DL-03 출고 후 1~2일 도착, 제주·도서산간은 2~3일 더 걸리고 추가 배송비 3,000원.
- DL-04 도착 예정일은 지어내지 않는다.
- DL-05 주문 때 결제한 배송비는 주문에 저장되며(무료배송이면 0원) 전체 취소 때 환불한다. 반품(상품불량 포함)에서는 환불하지 않는다.
- DL-06 무료배송은 주문 상품 금액이 3만 원 이상일 때 적용된다. 출고 전 일부 취소나 단순변심 일부 반품으로 남은 금액이 3만 원 미만이 되면 처음 면제된 배송비 3,000원을 환불에서 뺀다(주문당 한 번).
